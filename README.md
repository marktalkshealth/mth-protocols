# Mark Talks Health — course software (master)

Each folder is one course's protocol app, published by Netlify:

| Folder | Course |
|---|---|
| `gut/` | Gut Health Protocol |
| `sugar/` | Blood Sugar & Metabolic Repair (Diabetes course) |
| `glp1/` | GLP-1 Muscle Protection Protocol |

Courses load these with a small embed code (see `embed-codes.md`), so any change saved here
goes live in every course within about a minute. No re-pasting into LearnWorlds.
